\section{Method}
The reported fixes were retested independently, not by their status labels. The current source of all
eighteen repositories was re-read, the automated checks were re-run against that source and the live
backend, and an isolated copy of the platform was rebuilt to re-run the write-side reproductions and
the full probe battery. Every write was rolled back; no live or real data was touched.

\section{One caveat worth deciding on}
Several of the access fixes work only because staff accounts no longer carry the \texttt{System~Manager}
role --- the underlying checks still exempt that role. If any account is given it again, those issues
return for that account. How that role is granted is worth governing explicitly.

\section{Where the detail is}
The per-item status is in the bug tracker, in the \emph{Today's Status} column. The items still open,
grouped by root cause with the structural fix for each, are in the remediation plan.
